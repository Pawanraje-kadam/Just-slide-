# AI-Assisted Software Development
Why Can AI-Generated Code Pass Tests Yet Still Contain Serious Bugs? | Intermediate | Verification | Tests check the cases someone thought to write. Generated code can satisfy those cases while mishandling boundaries, failures, or the requirements nobody encoded. | Passing tests feels like proof, but AI-assisted development makes it more important to ask what the tests do not cover. | What classes of defects would a generated implementation hide from a happy-path test suite? | ai-coding, testing, verification
How Should Developers Verify AI-Generated Dependencies? | Intermediate | Code Review | Suggested packages may not exist, may be typosquats, or may be unmaintained. Verification means checking provenance, version, license, and actual API behavior. | Dependency mistakes are hard to reverse and can introduce supply-chain risk into otherwise reviewed code. | What checklist would you require before accepting a new package suggested by a coding assistant? | dependencies, supply-chain, ai-coding
What Makes a Codebase Easy for AI Agents to Navigate? | Intermediate | Context Engineering | Agents rely on naming, module boundaries, tests, and documentation to decide where changes belong. Ambiguous structure forces guesswork and wider diffs. | As more code is written by agents, codebase legibility becomes an engineering requirement rather than a style preference. | Which structural signals help an agent find the right file without loading the entire repository? | codebase-design, ai-agents, maintainability
How Do Context Windows Affect Long-Running Coding Tasks? | Intermediate | Context Engineering | A context window is a working memory budget. When relevant files and history exceed it, early decisions get dropped and consistency degrades. | Long tasks fail less from model capability than from losing the thread of prior constraints. | How would you summarize and checkpoint a task so important decisions survive context limits? | context-windows, ai-coding, task-design
Why Are Tests Your Best Defense When Pairing With an AI? | Beginner | Verification | Tests turn vague intentions into executable expectations. They catch regressions and force both human and model to agree on behavior before code changes. | The faster code arrives, the more valuable an independent signal of correctness becomes. | Which behaviors of an existing function would you pin with tests before letting an assistant modify it? | testing, ai-coding, regression
How Can Developers Detect Subtle Errors Introduced by AI Refactoring? | Advanced | Code Review | Refactors can preserve syntax while changing evaluation order, error handling, or edge-case behavior. Superficial review sees cleaner code and misses semantic drift. | Generated refactors are persuasive precisely because they look more organized than the original. | What diff-level checks reveal semantic changes that a green test suite might miss? | refactoring, code-review, ai-coding
What Are the Security Risks of Autonomous Coding Agents? | Advanced | Agent Safety | Agents with shell, network, and repository access can execute malicious instructions, expose secrets, or modify infrastructure far beyond the requested change. | Autonomy multiplies both productivity and blast radius, so permission design becomes the safety mechanism. | What least-privilege sandbox would let an agent do useful work while limiting damage? | agents, security, autonomy
How Should Engineers Review an AI-Generated Pull Request? | Intermediate | Code Review | Review must check requirement coverage, hidden assumptions, new dependencies, and test quality, not just whether the diff looks plausible. | Reviewers anchor on style and miss architectural or security failures when the volume of generated code rises. | What would you add to a review rubric specifically for generated pull requests? | pull-requests, code-review, ai-coding
Why Does Planning Before Code Improve AI Assistance? | Intermediate | Developer Workflow | A plan exposes assumptions and sequencing before implementation. It gives the model a stable target and gives the developer a place to intervene cheaply. | Steering a plan takes minutes; unwinding a wrong implementation can take days. | How detailed should a plan be before asking an assistant to write code? | planning, ai-coding, workflow
When Should You Not Use an AI Coding Assistant? | Beginner | Developer Workflow | Assistants are less helpful when the task depends on unstated context, novel architecture, sensitive data, or a domain where verification is expensive. | Knowing when to slow down is part of using these tools responsibly. | Which of your current tasks would be riskier to delegate than to write yourself? | ai-coding, judgment, risk

# DevOps & Platform Engineering
What Makes a Deployment Strategy Reversible? | Intermediate | Deployment | Reversibility requires compatible data schemas, versioned artifacts, preserved configuration, and a known-good path back. Stateless code is easy to roll back; database changes often are not. | A rollback that corrupts data is worse than a failed deploy. | Which schema changes make a rollback impossible without data loss? | deployment, rollback, databases
Why Do Blue-Green Deployments Still Break? | Intermediate | Deployment | Blue-green swaps traffic between environments, but shared databases, cached sessions, and external integrations can make both versions run simultaneously. | Isolation is the part that is easy to claim and hard to achieve. | What happens when the old and new versions write to the same database during a switch? | blue-green, deployment, compatibility
How Does Infrastructure as Code Drift? | Intermediate | Infrastructure as Code | Manual changes, provider updates, and partial applies move real infrastructure away from the declared state. The next apply may try to undo or conflict with those changes. | Drift turns infrastructure definitions into optimistic fiction. | How would you detect drift without applying a destructive plan? | infrastructure-as-code, drift, terraform
What Makes a CI Pipeline Fast Enough? | Beginner | CI/CD | Feedback speed depends on caching, parallelism, test selection, and avoiding redundant work. A pipeline that takes an hour stops being part of the development loop. | Slow CI encourages batching, larger risky changes, and bypassing checks. | Where does your pipeline spend time that does not depend on the code being tested? | ci, feedback, caching
Why Are Build Caches Hard? | Intermediate | CI/CD | A cache is only valid when its key captures every input that affects output. Missing inputs produce stale artifacts; overly broad keys produce misses. | Trust in build caches depends on correctness, not just hit rate. | What inputs would you include in a cache key for a compiled frontend bundle? | caching, builds, correctness
How Does Feature Flagging Change Deployment? | Beginner | Release Engineering | Flags separate code deployment from feature exposure, enabling gradual rollout and instant rollback without redeploying. They also add states that must be cleaned up. | Flags shift risk from shipping code to managing runtime behavior. | How would you prevent stale flags from becoming permanent branches in production? | feature-flags, rollout, release
Why Is Canary Analysis Difficult? | Advanced | Deployment | A canary must distinguish real regressions from normal variance while traffic, seasonality, and user mix differ from the baseline. Small samples make conclusions noisy. | Automated rollback is only as good as the judgment behind it. | Which metrics would you compare between canary and baseline, and for how long? | canary, progressive-delivery, metrics
What Makes a Rollback Unsafe? | Advanced | Deployment | Rollbacks can reintroduce security holes, conflict with new data written by the current version, or fail because migrations are not backward compatible. | The ability to deploy is not the same as the ability to reverse a deploy. | What migration pattern keeps both old and new application versions working? | rollback, migrations, safety
How Do Platform Teams Measure Developer Productivity? | Intermediate | Developer Platforms | Useful measures focus on flow, feedback, and cognitive load rather than raw commit or story-point counts. Platform work should reduce toil and waiting. | Metrics that reward activity can make the platform slower and less trustworthy. | Which waits in the developer workflow would a platform team try to remove first? | developer-productivity, platform-engineering, metrics
